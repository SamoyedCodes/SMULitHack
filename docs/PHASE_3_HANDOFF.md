# Phase 3: grounded extraction (next checkpoint)

Phase 2 reads files locally without importing Gemini. Keep that property: loss of model access must never prevent original retention, OCR, conversion or source viewing.

- `backend/worker.py` now handles **only** `kind='ingestion'` jobs. It checkpoints every page and produces `text_ready`, `needs_source_review`, or `failed`. Original `document`/`conflict` jobs remain untouched. `backend/analysis_worker.py` preserves the old coupled draft for reference; do not start it as a second concurrent worker.
- Add extraction as a separately queued stage processed by the single backend-managed worker. Review the draft `llm.py`, `evidence.py`, and analysis worker first. Gemini construction must be lazy and occur only for explicitly enabled inference jobs. Preserve already-read pages and restartable extraction chunks/cache entries.
- Keep canonical `Document`, `Finding`, `Evidence`, `Page`/`Span` and all eight field names. Ground every asserted value; retain multiple findings, whose obligation it is, conditions, exceptions, referenced schedules and unknown inputs. Do not use prototype `contracts/actions` records.
- Implement grounded party/SME selection, structured LLM extraction and support review, deterministic citation validation, explained confidence/provenance and completeness. Reading/OCR confidence is not legal confidence. Every field must have explicit unresolved representation if it cannot be established.
- Replace the disabled `/api/settings/sme` route and add typed extraction/job responses. Regenerate OpenAPI, fixtures and TypeScript using the documented commands; enable extraction only when its tests pass. Leave deadlines, conflicts, handoff and sample workspace disabled.
- Extend the current `SourceViewer` in `frontend/src/Ingestion.tsx`: it already renders physical page images and highlights source-coordinate boxes. Link each finding to its exact physical page, clause and validated span IDs. Label DOCX as rendered pagination.
- Preserve the ingestion batch API and receipt history. `POST /api/batches` accepts `files` and an optional UUID `Idempotency-Key`; duplicates are keyed by bytes, format and ingestion version independently of Gemini configuration. Retrying a source read uses `POST /api/retry?document_id=...`; do not silently turn that into paid/provider work.
- Verify actual model access and free-tier capacity before enabling provider calls. The configured `gemini-3.8-flash` string is provisional and has not been verified. Never substitute paid inference silently.

Acceptance: all judged fields represented; exact citation checks and fabricated-quote rejection; unanswerable/missing-schedule cases unresolved; misleading document instructions treated as untrusted data; every page/chunk accounted for; quota/key/network failures visible and resumable. Use a separate reviewed extraction answer key and grouped holdout. Phase 2's seven generated files and 80-file load test establish ingestion behavior, not extraction accuracy.
